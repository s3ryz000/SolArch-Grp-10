# Capability Architectures

Capability-level views are the nine work packages (WP1–WP9) and their building blocks, all in `Barangay San Antonio Health Department - Phase E (Opportunities and Solutions)`:

- **E1 Architecture Roadmap**: sequence of the work packages in three transition stages (T1 quick wins, T2 equip and digitize, T3 integrate and extend)
- **E2 Architecture Building Blocks**: ABB-1 to ABB-9
- **E3 Solution Building Blocks**: SBB-1 to SBB-9
- **E4 Implementation and Migration Plan**: projects P1–P6, milestones and timing
