# Reference Library

External guidance, models and templates used to develop the architecture.

- **Standards bodies:** The Open Group (TOGAF® Standard), Department of Health, National Nutrition Council, PhilHealth, National Privacy Commission
- **Templates:** the TOGAF® template pack provided in the course; every deliverable in this repository is built on one of them
- **Reference model:** TOGAF Content Metamodel, tailored (see [Architecture Metamodel](../Architecture%20Metamodel/))
- **Viewpoint library:** every diagram and the phase folder where it is stored (see the repository document and the checklist workbook)
- **Naming convention:** folders `Barangay San Antonio Health Department - Phase X (Phase name)`; files `Barangay San Antonio Health Department - <code> - <document name>`

See also Section 3 of `Barangay San Antonio Health Department - Architecture Repository.pdf` in the parent folder.
