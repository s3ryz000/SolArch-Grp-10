# Architecture Metamodel

The TOGAF Content Metamodel, tailored for this engagement to **34 entities**:

| Change | Entities |
|---|---|
| Retained (26) | Core TOGAF entities used as defined |
| Deleted (3) | Product, Contract, Course of Action |
| Merged (7) | Logical and physical application, technology and data components; Service Quality; Information System Service |
| Added (8) | Individual Treatment Record, Consultation Encounter, Consent Record, Health Program, Monthly Program Report, GAMOT Dispensing Entry, Referral, Record Retention and Disposal Entry |

Source: A5 Architecture Definition, "Mapping to Reference Models" (`Barangay San Antonio Health Department - Phase A (Architecture Vision)`). The added data entities appear in the C1 Data Entity catalog and the Logical Data Diagram.

See also Section 3.8 of `Barangay San Antonio Health Department - Architecture Repository.pdf` in the parent folder.
